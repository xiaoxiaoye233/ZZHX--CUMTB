数据字典说明

本文件说明 `dataset` 目录下每个文件的字段、类型与取值范围。怎么算出来的见同目录 `数据口径.md`；版本号与生成时间以 `index.json` 为准，本文件不重复记版本号。

适用对象：直接读 CSV / JSON 的人，以及调用这些文件的接口。

通用约定

同一含义在两种格式里各有一个名字，JSON 用英文键，CSV 用中文列名，一一对应。例如 JSON 的 `conclusion_level` 就是 CSV 的「档位」。

空值：JSON 写 `null`，CSV 写空单元格。空值只表示「这里没有数」，不表示 0。0 是一个真实分数。

比率一律 0 到 1 之间的小数，保留 4 位，百分比在展示层换算。

日期写 `YYYY-MM-DD`。时间写 `YYYY-MM-DD HH:MM`。

编号规则：学生 `D01`–`D40`；班级 `DC01`、`DC02`；考试 `N01`、`N02`；题目 `Q001`–`Q054`；学习卡 `L01`–`L03`；教材条 `B01`–`B08`；作答记录 `DR` 加四位序号。指标编号形如 `T02I3`，前三位是主题，后两位是主题内序号。

一、每人包 `Dxx.json`

文件是一个对象，四块：`student`、`question_records`、`indicator_summary`、`exam_comparison`。

1.1 `student`（概况，1 个对象）

| 字段 | 中文 | 类型与取值 | 含义 |
| --- | --- | --- | --- |
| `student_id` | 学生 | 字符串，`D01`–`D40` | 学生编号，与原始 `作答记录.csv` 的「学生编号」一致 |
| `class_id` | 班级 | `DC01` 或 `DC02` | 所属班级 |
| `grade` | 年级 | 整数 | 七年级，值为 7 |
| `record_count` | 记录数 | 整数 | 进入统计的有效作答记录条数，不含被剔除的 |
| `distinct_question_count` | 不同题目 | 整数 | 做过的不同题目数，跨场同题只算一道 |
| `available_question_count` | 他能考到 | 整数 | 在已教学且他参加过的考试里出现的题目总数，上限 54 |
| `score_total` | 得分 | 整数 | 有效记录得分合计 |
| `full_score_total` | 满分 | 整数 | 有效记录满分合计 |
| `score_rate` | 得分率 | 0–1 小数 | `score_total ÷ full_score_total`；分母为 0 时写 `null` |
| `attended_exams` | 参加的考试 | 字符串数组，取值来自 `N01`、`N02` | 有作答记录的考试 |

1.2 `question_records`（逐题记录，数组）

一行是一条有效作答记录。被剔除的记录不在这里，见 `04_质量与剔除/被剔除记录`。

| 字段 | 中文 | 类型与取值 | 含义 |
| --- | --- | --- | --- |
| `record_id` | 记录编号 | 字符串，`DR` 加四位 | 与原始 `作答记录.csv` 一致 |
| `exam_id` | 考试 | `N01` 或 `N02` | 所属测验节点 |
| `question_id` | 题目 | `Q001`–`Q054` | 材料编号 |
| `theme_id` | 主题 | `T01`–`T03` | 该题所属主题 |
| `indicator_id` | 指标 | 形如 `T01I1` | 该题对应的指标，一题只对应一个 |
| `full_score` | 满分 | 整数，1 或 3 | 该题满分 |
| `score` | 得分 | 整数，0 或正数 | 该题得分；空表示没有分数，与 0 分不同 |
| `score_rate` | 得分率 | 0–1 小数 | `score ÷ full_score` |
| `rubric_scores` | 评分点 | 字符串或空 | 原始文本，形如 `Q011P1=1；Q011P2=1；Q011P3=0`；一分题通常为空 |
| `counted_in_denominator` | 计入分母 | `true` / `false` | 是否计入得分率分母。`false` 只出现在被剔除的记录上 |
| `grading_flag` | 判分标记 | `正常`、`已改判`、`总分与分项不符`、`答案一致但判0`、`超满分` | 判分可靠性，`正常` 以外的记录见 `04_质量与剔除/判分存疑` |

1.3 `indicator_summary`（指标汇总，12 行）

九行是九个指标，三行是三个主题的小计。用 `row_type` 区分：`indicator` 为指标行，`theme` 为小计行。

| 字段 | 中文 | 类型与取值 | 含义 |
| --- | --- | --- | --- |
| `row_type` | 行类型 | `indicator` 或 `theme` | 指标行或主题小计行 |
| `indicator_id` | 指标 | 形如 `T01I1`；小计行为 `T01 小计` | 指标编号 |
| `theme_id` | 主题 | `T01`–`T03` | 所属主题 |
| `questions_in_bank` | 全库题数 | 整数 | 该指标（或主题）在全库中的题目数 |
| `questions_available` | 他能考到 | 整数 | 在已教学且他参加过的考试里出现的题目数；0 表示这段时间没考到 |
| `distinct_attempted` | 做过不同题目 | 整数 | 他实际做过的不同题目数 |
| `evidence_threshold` | 判定线 | 整数，2 或 3 | 判断档位所需的题目数；小计行固定为 3 |
| `coverage_rate` | 覆盖率 | 0–1 小数或 `null` | `distinct_attempted ÷ questions_available`；可考为 0 时写 `null` |
| `score` | 得分 | 整数 | 该指标（或主题）的得分合计 |
| `full_score` | 满分 | 整数 | 对应满分合计 |
| `score_rate` | 得分率 | 0–1 小数或 `null` | `score ÷ full_score`；没有计入的记录时写 `null` |
| `conclusion_level` | 档位 | `证据充足`、`证据偏少`、`证据不足` | 现有数据是否足以判断，只看题量不看得分 |
| `reason` | 档位说明 | 五种固定句子之一，或 `null` | 落入该档位的原因；`null` 只出现在证据充足档 |
| `curriculum_scope` | 课标范围 | 字符串 | 形如 `CR01 ①②③⑤ P62/55`，后两段是课标文件页与书上页码 |
| `textbook_scope` | 教材范围 | 字符串 | 形如 `上册68-109`，多段用分号分隔 |
| `supplementary_question_ids` | 可补练习题 | 字符串数组或 `null` | 可补的题目编号；小计行写 `null` |

1.4 `exam_comparison`（分场对比，数组）

按考试乘指标展开，每场末尾一行是该场的合计。`row_type` 取值 `indicator` 或 `exam_total`。

| 字段 | 中文 | 类型与取值 | 含义 |
| --- | --- | --- | --- |
| `row_type` | 行类型 | `indicator` 或 `exam_total` | 指标行或该场合计行 |
| `exam_id` | 考试 | `N01` 或 `N02` | 所属考试 |
| `theme_id` | 主题 | `T01`–`T03` | 所属主题 |
| `indicator_id` | 指标 | 形如 `T01I1`；合计行为空 | 指标编号 |
| `participated` | 是否参加 | `true` / `false` | 该场有无作答记录 |
| `questions_in_exam` | 本场题数 | 整数 | 该场该指标出了几道题 |
| `distinct_attempted` | 做过 | 整数 | 该场该指标做过几道 |
| `score` | 得分 | 整数或 `null` | 该场该指标得分；没有作答记录时写 `null` |
| `full_score` | 满分 | 整数或 `null` | 同上，满分 |
| `score_rate` | 得分率 | 0–1 小数或 `null` | `score ÷ full_score` |
| `teaching_status` | 教学状态 | `已教`、`部分教到`、`未教`、`未提供`、`null` | 该场该指标在考前是否已教；合计行为 `null` |
| `note` | 说明 | 字符串 | 一句话描述该场该指标的情况，如「这场出了 6 道，他做了 3 道，得 1/5 分」 |

七、质量四表与基准数字

7.1 `质量检查清单.csv`（9 行）

列：问题代码、严重程度、记录数、样例记录、说明、处置、影响分母。`严重程度` 取 `高`、`中`、`低`；`影响分母` 为 `true` 表示这类记录已从得分率分母中剔除。

7.2 `被剔除记录.csv`（18 行）

列：记录编号、学生、题目、考试、修订版本、评分状态、得分、满分、剔除原因。`剔除原因` 取 `旧修订版本`、`待评分`、`未作答`、`超满分` 四类。

7.3 `判分存疑.csv`（9 行）

列：记录编号、学生、题目、判分标记、说明。`判分标记` 取 `已改判`、`总分与分项不符`、`答案一致但判0`。

7.4 `多版本明细.csv`（14 行 = 7 组 × 2 条）

列：作答事件、学生、题目、修订版本、评分状态、得分、是否采用。`是否采用` 为 `是` 的那条进了统计，`否` 的那条是被替代的旧版本。

7.5 `基准数字.json`

对象四个键：`说明`、`怎么用`、`rule_set`、`数字`。`数字` 是数组，每条含 `name`（英文标识）、`expected`（期望值）、`actual`（本次实际值）、`unit`（单位）、`description`（一句话说明）。`expected` 与 `actual` 相等表示这批数据未偏离基准。

8.2 `校验报告.md`

生成时执行的检查项清单与逐项结果，分五组：结构、算账、参考数字、基准、落盘。某项失败时该次生成不会写盘，所以报告里出现的全部是已通过的项。
