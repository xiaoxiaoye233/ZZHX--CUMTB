# 数据字典

本目录是「干净数据集」，给程序读（JSON）也给人看（CSV）。**这里只有数字与出处，没有一句结论**——结论由 Agent 侧负责。

## 一、三条通用约定

**1. 空值一律 `null`（CSV 里是空单元格），绝不用 0 代替。**

| 写法 | 含义 |
|---|---|
| `null` | 没考到 / 这场没出这个指标的题 / 学校还没教 / 老师还没判分 |
| `0.0` | 考了，一道都没得分 |
| `1.0` | 考了，全对 |

这条最容易出错。前端判 `null` 显示「—」或「未参加」，判 `0` 显示「0 分」，两者不能混。

**2. 比率统一 4 位小数**，`0.3333` 而不是 `33.33%`——换算交前端。

**3. 键名英文，值保留中文。** `score_rate` 是键，`代数式与整式运算` 是值。

## 三、先看这一份：`04_质量与剔除/基准数字.json`

30 个关键数字，每条带 `expected`（人写的期望值）、`actual`（本次跑出来的）、`unit`、`description`、`source`。

```json
{"name": "overall_score_rate", "expected": 0.5704, "actual": 0.5704,
 "unit": "比率", "description": "745÷1306", "source": "口径说明"}
```

**什么时候用它**：改了 `dataset.py` 或口径代码之后，跑一次生成脚本——`校验报告.md` 里「基准」组的那些行就是逐条比对。只要有一条对不上，说明数字被改动了，先查清原因再往下走（我们踩过「57.04 被算成 57.94」这种坑）。

## 四、`00_字典/课标原文`　课标里到底写了什么

个人包里的 `curriculum_scope` 是短号（`CR01 ②③⑤ P62/55`），编号是**每个小节自己从 ① 数的**，在 PDF 里直接搜"②"对不上，所以原文单独放一份，可以直接对照。

文件：`00_字典/课标原文.json` + `00_字典/课标原文.csv`（CSV 表头：`小节｜主题｜课标小节｜条目｜课标原文｜用于指标｜文件页｜正文页`，20 行）。

三块内容：

| 块 | 条数 | 是什么 |
|---|---|---|
| `小节` | 3 | 三个小节的范围与规则（`group`、`theme_id`、`heading_path`、`file_pages`、`body_pages`、`note`、`item_count`） |
| `原文条目` | 20 | 每条课标**一字不改**（`item_label`、`text`、`used_by_indicators`、`file_page`、`body_page`） |
| `指标对应` | 13 | 哪个指标用了哪一条（`indicator_id`、`citation`、`item_label`、`used_part`、`quote_full`、页号） |

三小节分别是：`CR01`「（3）代数式」①–⑨（9 条，⑧⑨ 在文件第 63 页开头）、`CR02`「（1）方程与方程组」①–⑧、`CR03`「（2）不等式与不等式组」①–③。合起来 20 条，其中 13 条被九个指标引用，其余 7 条（如 ④ 科学记数法、⑥ 乘法公式、⑦ 因式分解）本次不涉及，也照样列出来。

两条约定：

1. **`text` 是原文**：照抄，标点都不动，只去掉句末的句号。要引用课标就引这一列，不要引 `curriculum_scope` 那个短号。
2. **`used_part` 是我们写的**：原文一条含两个要求、被两个指标分开用时，这里写明"前半句 / 后半句"，`quote_full` 仍是整条原文。所以看到 `used_part` 有字，说明这条课标被拆着用。

怎么核对：`05_出处截图/kb_p62.png` 是文件第 62 页（书上印 55 页），找加粗的「（3）代数式」，下面 ①–⑦ 依次排列；`kb_p63.png` 是第 63 页（印 56），开头 ⑧⑨ 仍属「（3）代数式」，再往下才是「2. 方程与不等式」。

## 五、个人 JSON 的四块

### 0　顶层 `student`　这份包的抬头

| 字段 | 含义 | 例 |
|---|---|---|
| `student_id` / `class_id` / `grade` | 学号 / 班级 / 年级 | `D17` / `DC01` / `7` |
| `record_count` | 计入统计的作答记录数 | 4 |
| `distinct_question_count` | 做过几道不同的题（同题两场只算一道） | 4 |
| `available_question_count` | 他参加过的那几场里一共能考到多少题 | 27 |
| `score_total` / `full_score_total` / `score_rate` | 总分 / 总满分 / 总得分率 | 8 / 8 / `1.0` |
| `attended_exams` | 参加过哪几场 | `["N01"]` |

### 1　`question_records`　一行 = 一次作答

| 字段 | 类型 | 含义 | 例 |
|---|---|---|---|
| `record_id` | string | 记录编号，可反查原始表 | `DR0369` |
| `exam_id` | string | 哪场考试 | `N01` |
| `question_id` | string | 哪道题（题型/主题/指标/满分去 `00_字典` 查） | `Q014` |
| `theme_id` | string | 主题 | `T01` |
| `indicator_id` | string | 指标 | `T01I1` |
| `full_score` / `score` | int | 满分 / 得分 | 3 / 3 |
| `score_rate` | float | 得分率 | `1.0` |
| `rubric_scores` | string | 评分点得分原文 | `Q014P1=1；Q014P2=1；Q014P3=1` |
| `counted_in_denominator` | bool | 是否计入统计（本表只放计入的） | `true` |
| `grading_flag` | string | 判分标记 | `正常`（另见 04 目录） |

> 这一块**不再重复**主题名、指标名、题型——它们在 `00_字典` 里查一次即可，40 份包里省掉这些重复字符串。

### 2　`indicator_summary`　一行 = 一个指标（9 行）+ 三行主题小计

| 字段 | 含义 | 例（D17 / T01I1） |
|---|---|---|
| `row_type` | `indicator` 或 `theme` | `indicator` |
| `indicator_id` | 指标（名字去 `00_字典/指标字典.json` 查） | T01I1 |
| `theme_id` | 主题 | T01 |
| `questions_in_bank` | 全库这个指标一共几道题 | 6 |
| `questions_available` | **他能考到几道**（参加过的考试里出的） | 6 |
| `distinct_attempted` | 做过几道不同题目（同题两场只算一道） | 2 |
| `evidence_threshold` | **判定线**：做过几道不同题才算"证据充足"（= max(2, min(min(3, 全库题数), 能考到))；主题小计固定 3） | 3 |
| `coverage_rate` | 覆盖率 = 做过 ÷ 能考到 | `0.3333` |
| `score` / `full_score` / `score_rate` | 得分 / 满分 / 得分率（没作答时三者全 `null`） | 4 / 4 / `1.0` |
| `conclusion_level` | 这一格能下什么判断：`证据充足` / `证据偏少` / `证据不足`（判定线＝先取 min(3, 全库题数)，再和他能考到的题数取小，最低 2 道；见 `evidence_threshold` 列） | `证据偏少` |
| `reason` | 为什么是这个档位（中文一句，`证据充足` 档为 `null`） | 做过的题还不够多，先记下 |
| `curriculum_scope` | 课标范围（**主题级**，`P` 前是 PDF 页、`/` 后是书上页码） | `CR01 ②③⑤ P62/55` |
| `textbook_scope` | 教材范围（**主题级**） | `上册68-109` |
| `supplementary_question_ids` | 还能补的题（同指标、他没做过、在他可考范围内） | `Q001(1分)、Q002(1分)` |

`conclusion_level` 三档的意思：**证据充足**＝够条件下判断（看 `score_rate` 就说得出"会 / 不会"）；**证据偏少**＝题目做得太少，只能看方向；**证据不足**＝一道没做或这部分没教到，不下判断。三档只看"做了几道"，不看分数高低——这是数据层的判断，不看分数的结论由上层再写。

`row_type=theme` 的行是三行小计，`indicator_id` 写作 `T01 小计`，`questions_in_bank` / `questions_available` 是该主题三指标之和（D17 的 T01 可考 18），覆盖率用同一公式算，`conclusion_level` 是该主题三格档位的合成，`reason` 恒为 `null`。

> **为什么个人包里没有指标名、主题名**：它们在 `00_字典/指标字典.json` 里查一次就够，40 份包重复写会白占 4 KB/人。班级表与主题表只有 27 / 40 行，规模小，所以直接带上了名称。

### 3　`exam_comparison`　一行 = 一场考试 × 一个指标，只保留"这场真出了这个指标的题"的行，另加每场一行小计

D17 只有 7 行（N01 的 5 个指标 + 2 行小计），而不是固定 18 行——没参加的考试、这场没出的指标都不占行，信息收在小计的 `note` 里。

| 字段 | 含义 |
|---|---|
| `row_type` | `indicator` 或 `exam_total`（小计） |
| `exam_id` | 哪场 |
| `theme_id` / `indicator_id` | 主题 / 指标（小计行的 `indicator_id` 写作 `N01 小计`） |
| `participated` | 他参加了这场没有 |
| `questions_in_exam` | 这场出了几道该指标的题（小计行＝本场可用题数） |
| `distinct_attempted` | 这场他做了几道 |
| `score` / `full_score` / `score_rate` | 这场的得分与得分率（没作答时全 `null`） |
| `teaching_status` | 这场时该指标教到哪一步：已教 / 部分教到 / 未教。另有第四种 `未提供`：这场既没有手写记录、也没出过这个指标的题，推不出来就不硬猜（现有两场里没出现） |
| `note` | 例如「没有参加这场考试」「另有这些指标这场出了题但没有有效记录：T02I2…」 |

## 六、口径（写在 `口径说明.md`，这里列要点）

1. **分母只算「已评分且得分≤满分」的记录**：806 条 → 788 条，被剔除的 18 条在 `04_质量与剔除/被剔除记录` 里逐条可查。
2. **同一道题两场各做一次**：算分按两次，数题只算一道。
3. **不做加权合成**：覆盖率是证据量、得分率是质量，两者并列，**不合成"掌握度"**。
4. **判分存疑只标注不改分**：一律采用官方得分，9 条存疑在 `04_质量与剔除/判分存疑`。

## 附二：`04_质量与剔除/` 四张表　　数据是怎么被筛下来的

生成数据集时先"记账"再"算数"，这四张表就是那本账。看它们的意义：**任何一个数字都能被这四张表解释**。

| 文件 | 行数 | 一行是什么 | 列（中文表头就是 CSV 第一行） |
|---|---|---|---|
| `质量检查清单.csv` | 9 | 一类数据问题 | `问题代码` `严重程度` `记录数` `样例记录` `说明` `处置` `影响分母` |
| `被剔除记录.csv` | 18 | 一条不进统计的作答记录 | `记录编号` `学生` `题目` `考试` `修订版本` `评分状态` `得分` `满分` `剔除原因` |
| `多版本明细.csv` | 14 | 一次"同一作答事件有多个修订版本" | `作答事件` `学生` `题目` `修订版本` `评分状态` `得分` `是否采用` |
| `判分存疑.csv` | 9 | 一条"判分看着不对、但不改分"的记录 | `记录编号` `学生` `题目` `判分标记` `说明` |

读法要点：

- `严重程度` 只有三档：`error`（这条记录的分数不能进统计）/ `warning`（进统计但标出来）/ `info`（只留痕）。九类问题里真正把记录剔出去的是"待评分""未作答"，外加 2 条得分超满分。
- `剔除原因` 有四种，取值就是这四句：`待评分（老师还没判分）` 4 条 / `未作答（空答案）` 5 条 / `旧修订版本（已被更高版本替代）` 7 条 / `得分超满分（录入错误）` 2 条，合计 18，与 `index.json` 的 `quality.excluded_records` 对得上。
- `判分标记` 的取值就是 `src/lib/grading.py` 里那五个：`正常` / `已改判` / `总分与分项不符` / `答案一致但判0` / `得分超过满分`。**只标不改**，官方得分照用。
- `是否采用` = `是` 的那一行是被算进统计的那一版，同一事件其余行是 `否`。
