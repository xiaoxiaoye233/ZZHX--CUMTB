# 数据层交付说明（给整理目录的人）

一句话：**这个包里除了这一个说明文件，其他东西全是代码生成的，不要手改。**

---

## 一、包里有什么

```
dataset/                       ← 数据集本体，118 个文件 3.1 MB
  00_字典/                     指标字典、考试字典、题目字典、课标原文（csv + json）
  01_按学生/D01…D40/           每个学生一个目录：Dxx.json（四块数据）+ Dxx_速览.csv
  02_按班级/                   班级总表 40 行、班级_指标汇总 27 行、班级_主题汇总 9 行
  03_按主题/                   T01 代数式与整式运算 / T02 方程与方程组 / T03 不等式与不等式组，各 40 行
  04_质量与剔除/               质量检查清单、被剔除记录、多版本明细、判分存疑、基准数字
  05_出处截图/                 课标那两页的截图 + 赛题封面 + 赛程图
  06_题目内容.json             54 道题的题干/选项/答案/解析
  index.json                  总入口：数据版本号、数据质量、40 个学生的索引
  数据字典.md / 口径说明.md     字段与口径说明
  校验报告.md                  本次生成的断言结果（逐条 PASS）

src/lib/                      ← 生成这些数据的代码，11 个模块
src/steps/13_build_dataset.py ← 唯一入口
```

**`dataset/` 里只有三样东西是手写的**：`05_出处截图/`（4 张图）、`数据字典.md`、`口径说明.md`。
其余全部是每次重新生成的，包括 `index.json`、`校验报告.md`、`基准数字.json` 和所有 csv / json。

---

## 二、怎么重新生成

```bash
D:\AI+\env\python.exe src\steps\13_build_dataset.py
```

跑完会打印一行：

```
共 95 条断言通过，0 条失败。数据版本 20261122-191758，台账 data/builds/20261122-191758/。
```

**断言不过就不会落盘**：脚本先写临时目录，全部通过才两份改名换上去，中途出错 `dataset/` 一个字都不变。

依赖只有三个：`pandas`、`pydantic`、`openpyxl`（见 `requirements.txt`）。

---

## 三、如果整理目录，要改哪里

11 个模块之间用的是**扁平导入**（`from content_map import ...`、`from tools import ...`），能互相找到只因为入口脚本把 `src/lib` 放进了 `sys.path`。

所以：**只要这 11 个文件还待在同一层目录里、那个目录进了 `sys.path`，它们之间一行都不用改；目录叫什么名字都行。**

要改的只有 `src/steps/13_build_dataset.py` 开头这几行：

| 行 | 现在写的是 | 什么时候改 |
|---|---|---|
| 23 | `ROOT = Path(__file__).resolve().parents[2]` | 入口文件所在目录的层级变了（比如从 `src/steps/` 挪到 `pipeline/steps/`），`parents[]` 里的数字跟着改 |
| 25 | `sys.path.insert(0, str(SRC / "lib"))` | `lib` 目录改名或挪走，改这里的路径 |
| 31 | `DATA_DIR = ROOT / "赛题数据" / …` | 赛题原始数据换位置 |
| 32 | `OUT = ROOT / "dataset"` | 数据集目录改名或挪走 |

**两个提醒：**

1. **11 个模块必须整体搬。** 它们互相引用（`tools` 引用 `facts`、`contracts`、`content_map`、`clean`、`grading`、`io_layer`），拆开就会 `ModuleNotFoundError`。
2. **改完跑一次上面那条命令。** 95 条断言全过，就说明路径都接对了。

## 四、口径还会变

`数据口径卡.md` 里的规则（R1–R13）在后续会议里可能调整。

**调整后不用手工改数据，改代码重跑一遍就行**，`校验报告.md` 会重新给出断言结果。

所以这个包是"按现在的口径生成的一份快照"，不是最终版。
